About PneumoAI

Deep Learning for Medical Image Analysis & Classification

Project Overview

PneumoAI is an end-to-end computer vision application that leverages transfer learning with Convolutional Neural Networks (CNNs) to classify chest X-ray images for signs of pneumonia.

Pneumonia remains a severe pulmonary infection affecting millions globally. Rapid preliminary diagnostic screening can assist clinical triage workflows by highlighting high-risk chest X-ray scans.

Technical Summary
  • Base Model: VGG16 (ImageNet pre-trained weights)
  • Input Shape: 224 × 224 × 3 RGB tensor
  • Frameworks: TensorFlow 2.x & Keras
  • Application Server: Flask (Python 3.12)

Dataset & Architecture

Chest X-Ray Dataset

Source: Kaggle Chest X-Ray Images (Pneumonia)

Classes: NORMAL (1,583) vs PNEUMONIA (4,273)

Split: Training (5,216) / Validation (16) / Test (624)

Model Architecture Layers
  1. VGG16 Base Model: 13 Conv layers + 5 MaxPool layers (frozen ImageNet features)
  2. Global Average Pooling: Flattens spatial feature map dimensions
  3. Dense Layer: 128 units with ReLU activation
  4. Dropout Layer: 0.5 dropout rate for regularization
  5. Output Layer: Single neuron with Sigmoid activation
Important Disclaimer

This application is developed solely for educational and research demonstration purposes. It is not a certified medical device and must never be used for clinical decision-making or official patient diagnosis.
